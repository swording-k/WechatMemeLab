# 效果设计与验收标准

日期：2026-10-09。用户确认：产品的核心是表情效果的审美和趣味性。以当前局部照片变形方向继续打磨，不靠模板数量证明产品质量。

## 参考与观察

参考：https://petpetgenerator.com/index.html 。本轮实际查看了页面中默认拍拍动画的不同画面：写真手部切图与简笔笑脸组合，手贴近并覆盖主体，主体被压扁。值得借鉴的是接触和受压之间的关系，以及手部素材与人物素材的反差，不直接复用其动画素材。

白底、透明底或铺满照片都只是构图选择。旧版的问题是照片移动与装饰缺少可信的作用关系，不能把“去掉白底”当作审美已经达标。

## 每个效果必须能解释清楚

1. **谁在对谁做什么**：例如手碰到脸，脸被揉扁；不要只有一个名字和无缘由的移动。
2. **主体怎样变化**：变化作用于照片中的主体或选中的局部，人物仍然认得出来；夸张也应有明确动作意图。
3. **何时接触、何时变形、何时恢复**：遮挡、作用点和时序一致；按压时变形，松开时回弹，允许夸张的过冲和停顿。
4. **笑点出现在哪里**：预备动作、意外、停顿或反差至少有一个具体设计，不能只把全部参数调大。
5. **适合怎样回复**：朋友、情侣、兄弟、闺蜜之间的抽象互动和暧昧反应。用户已排除泛泛助威、祝好运模板。

## 画面要求

- 人物或主要动作占据足够画面，小尺寸聊天中也能看懂。画面不能靠大块空白填充。
- 相机变化、整体照片变形、主体动作和局部液化是不同手段；按效果选用，不统一套一种算法。
- 接触不能漂浮、穿帮或突然断开；主体不能像一块无关的矩形贴纸在画面上滑动。
- 素材可保留粗糙、低清和拼贴反差，但动作应有设计。避免把所有效果做成规整的通用卡通贴纸。
- 不依赖文字才看懂动作；文字与动作互相补充。可生成无字版本检查。
- 循环首尾应有意安排，停顿、力度和回弹需要实际观看 GIF 判断。

## 验收方式

先制作少量可观看的效果，逐个打磨。至少检查近景照片、长方形照片、偏离中心的主体和小尺寸 GIF。需要选择主体时提供人工修正，不伪称自动人脸识别已实现。

技术检查证明能生成、能下载、尺寸和播放正常；审美验收单独记录。看整段循环，不仅看截图。用户没有认可时不能把效果称为已经做好。

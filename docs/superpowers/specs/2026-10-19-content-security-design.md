# 小程序内容安全整改

用户已授权实施：图片/视频GIF导出及公开反馈提交前进行真实微信内容安全检测；失败、超时、待复核、违规均不放行。不是删改隐私选项绕过审核。

复用现有meme-feedback-api HTTP函数，增加小程序wx.login换取OpenID的短期签名会话、文字msgSecCheck、媒体mediaCheckAsync与微信签名回调。AppSecret仅后端环境变量。独立meme_security_jobs集合和meme-security存储前缀，不影响FitGenius服务。

每一帧输出都转为单帧GIF检测（不只抽首帧），文字单独检查；生成成品可在本地继续计算但检查未全部通过不展示下载/保存入口。异步回调未到、出错或超时均保持阻断。反馈正文及附件同样检测，通过后签发绑定实际内容的短期凭证；反馈后台在写入pending公开队列前验证凭证，防止只做前端拦截。

微信回调使用独立Token验证签名；临时媒体在任务完成后删除，失败残留任务保守过期并提供清理任务，不承诺未实现的自动生命周期。网络检测需用户知情，补充隐私说明。真实AppSecret/回调配置与真机检测必须完成后才可重新提审。

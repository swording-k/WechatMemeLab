# 手机照片编辑工作区验证

分支：`codex/mobile-photo-studio`。基于原 AI 内测开发分支，不合并 main、不发布。

## 布局与实现选择

用户明确要求：手机竖屏下，上传、框选局部、选效果、改字不应反复滚动找预览；照片缩放和左右/上下位置用直接操作替代滑块。

复用现有 Canvas、photoPlacement/reframeFocus、图层 gestureDelta 和 GIF Worker；没有新增依赖。照片框选与变形中心、猫狗贴图在同一套坐标中工作，避免外接完整图片编辑组件造成两套取景。照片与框选的范围输入保留为内部状态，用户界面不再显示这些滑块。

手机工作区固定在当前视口：上方画布，下方“照片 / 效果 / 文字 / 动作”四个面板，仅面板内部滚动；底部 GIF 下载与尺寸选择独立。帮助教程和源码/作者入口放进手机帮助窗口。桌面恢复原有三栏布局，复用同一批 DOM 控件，切换不复制表单或丢失照片和文字。

## 操作检查

1. **上传照片：通过。** 在 390×844 视口通过真实文件选择器选择内置虚构人物 9:16 竖图，本地加载成功，照片工具可直接找到框选。图片未上传服务器。
2. **框选与取景：通过浏览器直接操作。** 原图拖出人脸局部方框，应用后保持为照片取景；选框支持移动、四角缩放，另有键盘移动和大小按钮。真实照片拖动后位置变为 x=25.9/y=19.2；放大按钮把 zoom 从 1 改为 1.15。双指逻辑的手势中心不漂移已有几何测试。
3. **效果与文字：通过。** 选猫咪效果、进入文字工具并输入“再摸一下”；画布与文字输入、导出按钮同屏。320×568 视口无横向溢出，画布 top=108/bottom=271，文字 top≈419/bottom≈465，导出 top=480/bottom=524，均在当前视口。390×844 文字输入后文档 scrollY=0，整页不再被推走。自由捏图自动打开动作工具，真实拉拽后操作计数为1。
4. **GIF 导出：通过。** 实际下载并独立解码：240×240、29帧、无限循环、637259字节（约622KB）。预览编辑手柄不进入导出。
5. **帮助及桌面：通过。** 手机“怎么使用”打开教程窗口，返回后编辑继续；切到1280×900恢复三栏与15个玩法，预览350px；再次回手机保持文字和唯一画布/表单。检查到的页面日志只有开发连接信息，无运行错误。

## 验证层次与边界

- `npm test`：62项通过，其中新增照片缩放锚点、方形选区边界测试先失败后通过。
- `npm run build`、`git diff --check`：通过。
- 浏览器：390×844、320×568、1280×900，上传、框选、拖动、缩放按钮、选效果、改字、自由捏图、下载、帮助、响应式恢复已操作验证。
- 当前 IAB 的 `Input.dispatchTouchEvent` 不可用，未以脚本冒充真实双指实测。双指缩放与系统软键盘在真实 iPhone/安卓上的表现仍需手动验收。
- 本轮不改变 AI、后端或费用，没有进行收费生成。不宣称已部署或已通过微信/抖音客户端验收。

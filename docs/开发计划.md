# 表情包工坊开发计划

更新日期：2026-10-09。

## 用户确认的方向

用户用自己或朋友的照片做搞怪表情。保留人物的可辨识性，通过夸张变形、突然变化、停顿和反差表达聊天情绪。原来的摸摸头、捏捏脸、敲敲你及圆形头像加卡通手势方案被用户否定，已替换。

首版不提供微信/抖音收藏同步、收藏导出或自动导入。产品生成可由用户保存的 GIF 文件；客户端发送与收藏方式需实测。

## 当前九个玩法

| 玩法 | 画面变化 | 聊天用途 |
| --- | --- | --- |
| 你说啥？ | 正常画面短暂停留，两次突然放大，近景局部变形并抖动，然后恢复 | 震惊、疑惑，配“啊？”或“你再说一遍” |
| 精神状态良好 | 照片横向拉宽、纵向拉长、抖动，最后压扁停顿 | 崩溃、敷衍，配“别催了”“我很好” |
| 我来啦 | 从画面外冲入、碰撞压扁、旋转弹飞，再冲回来 | 插话、兴奋，配“我来了”“还有这种好事” |

整体照片和中部的非线性变形由 Canvas 完成，不识别人脸五官，不提供自动抠图。默认完整显示原图及长宽比例，用户可以调整缩放和位置。透明 PNG 合成到所选背景；没有透明 GIF 输出。

新增六个玩法：

| 玩法 | 画面变化 | 文案 |
| --- | --- | --- |
| 贴一下怎么了 | 同一照片的两个分身挤到一起再弹开 | 就要贴贴、别躲啊 |
| 偷偷靠近 | 从侧面探过来，停一下再退走 | 你在干嘛、想我没 |
| 亲完就跑 | 接近，留下嘴唇印记，旋转溜走 | 啵！溜了、不许追我 |
| 阴暗爬行 | 压成一条，在下方蠕动穿过画面 | 扭曲，蠕动 |
| 左右横跳 | 两侧反复蹦跳，落地压扁 | 略略略、抓不到我 |
| 害羞到蒸发 | 抖动、旋转缩小、淡出，再循环出现 | 啊啊不许看 |

贴贴目前使用同一照片的两个分身；没有双人分别上传。新效果仍不识别人脸五官。用户明确排除助威、好运等祝福型模板。

## 用户操作

选择玩法 → 上传自己的照片 → 调整主体位置 → 可选修改短句和强度/速度 → 预览 → 下载。人物示例仅用于演示，为内置工具生成的虚构成年人，见 `docs/素材来源.md`。

## 技术结构

TypeScript + Vite 静态站点；gifenc（MIT）编码 GIF；Web Worker 避免编码阻塞界面。

- `src/main.ts`：页面交互、照片输入与状态。
- `src/render/motion.mjs`：动作节奏和变形参数。
- `src/render/frame.ts`：照片渲染、局部变形和文字。
- `src/export/`：冻结导出状态，Worker 渲染和 GIF 编码。
- `tests/`：动作与 GIF 核心测试，实际浏览器交互。

照片不上传服务器；页面关闭后不持久保存用户照片。

# 照片取景、文字与贴图编辑

## 本轮修复

用户反馈：上传全身照会自动放大脸，不能自由缩小、移动或框选；猫狗贴图不能独立调整位置和角度。

根因：缩放下限为 1，照片按 cover 铺满；平移量只依赖超出画面的宽高，恰好填满的轴没有移动量；猫狗贴图只跟随自动检测的关键点角度，没有手动变换。

- 上传后默认完整取景，检测只定位动作区域；显式勾选“自动对准人脸取景”才改变照片构图。
- 照片缩放允许小于 1；双轴移动、直接拖动、完整照片与铺满切换，控制放在可见的照片区域。
- 在原图上拖出方形取景框，支持滑块微调位置和大小、取消与确认。输出继续是方形 GIF。
- 猫狗贴图独立移动、旋转、缩放；可摆正并重置或恢复检测角度。贴图编辑与照片移动、自由捏图互不抢操作。
- 文字已有左右/上下位置、快捷位置、字号、颜色、样式与重置；本轮复核了预览、导出、分享链接与移动端布局。
- 自动检测晚返回时保留用户手动调整。照片取景变化同步映射动作锚点，往返缩放不再因裁剪作用范围而永久缩小贴图。
- 预览与导出共用取景和贴图变换；编辑时定格便于摆放，切回“效果位置”播放动画。照片与坐标不写入玩法链接。

- `npm run build`：TypeScript 与 Vite 生产构建通过。
- 生产预览 `TEST_URL=http://127.0.0.1:4175/ npm run test:editor`：实际上传竖图、双轴拖动、原图框选、选区滑块、完整图切换、迟到检测保留编辑、猫狗贴图拖动/旋转/缩放、重置、文字位置独立保持、模式切换、320/390px 布局均通过；实际导出六份不同角度 GIF。
- 生产预览 `npm run test:caption`：文字位置、颜色、字号、四种样式的实际导出、链接往返、重置与手机布局通过。
- 生产预览 `npm run test:browser`：现有照片效果导出、竖图/横图/合照、失败恢复、手动定位降级、键盘、减少动态偏好与手机排列通过；测试期间没有照片外发请求。480px 导出期间主线程定时器最大间隔约 19ms，仅代表本机 Chrome。

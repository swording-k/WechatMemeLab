# 画布直接编辑验证

## 产品实现

- 文字和原有猫狗贴图可直接点选、拖动；选框手柄缩放和旋转，手机双指移动、缩放、旋转。
- 双指抬起一指后连续单指拖动，取消手势恢复起点；一次手势对应一步撤销／重做。
- 文字独立画布中心、缩放和旋转进入共用渲染和 GIF 导出；旧玩法链接仍可用，新链接保存文字变换。
- 文字与贴图位置滑杆默认折叠。选框、中心参考线与手柄属于 DOM，不能进入 GIF。手柄限制在画布可见区域。
- 画布空白第一次点击取消选择；随后继续原有效果位置工具。照片取景工具与自由捏图笔刷可独立使用。
- 双击文字聚焦真实输入框；方向键移动选中对象，手柄方向键微调大小／角度。

## 本地技术证据

- `npm test`：41 个单元测试通过，包含旋转命中、双指变换、角度跨越及文字变换分享。
- `npm run build`：TypeScript 检查和 Vite 生产构建通过。
- `npm run test:layers`：直接点选、拖动、手柄、撤销／重做、编辑定格／成品播放、触控连续拖动及取消、320/390px、捏图隔离、四个真实 GIF。
- `npm run test:editor`：完整照片、双轴取景、框选、人脸定位竞态、猫狗独立变换、六个 GIF、移动布局。
- `npm run test:caption`：文字位置、颜色、样式、四个 GIF、链接恢复及重置。
- `npm run test:sculpt`：笔刷、撤销清空、播放、换照片、移动布局和导出。
- `npm run test:browser`：六个旧玩法导出，竖图／横图／合照，错误恢复、降级定位、链接及 Worker 响应性。上传图片未产生向外发送请求。
- 独立 Pillow 解码文字旋转、摆正、猫、狗的成品：240 × 240，多帧、1600ms、无限循环。红色文字区域在预览与导出首帧的中心差小于 1px，边界差不超过 3px（缩放和 GIF 调色板造成的像素差）。

截图、GIF 和浏览器结果位于忽略的 `work/layers/`；生产构建证据位于 `work/layers-production/`、`work/editor-production/`。

# AI表情创作扩展实施计划

**Goal:** 普通用户从文字或照片开始生成静图，确认后继续生成动作，最后复用取景/配字/GIF工作台；保留直接照片动作和参考动作。

**Architecture:** 复用现有Wan异步provider、固定任务ID、云端事务预算、微信素材凭证与COS下载。新增draw/edit模式，静图和视频每一步由用户单独发起，使用不同任务ID，不静默串联收费。客户端先检测AI静图，再允许保存/继续编辑/生成动作。报价与实际扣款分离，未开通支付不收钱、不制造余额。

**Tech Stack:** Node fetch、CloudBase原有集合、Wan2.6异步API、原生微信WXML/JS、现有Vite网页、node:test。

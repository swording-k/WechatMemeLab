# 小程序0.1.6视频选择兼容修复

用户真机截图：选择视频后报`this.info.duration.toFixed is not a function`，没有设置视频path，生成按钮持续禁用。旧代码假定getVideoInfo.duration是number；字符串时长既无法调用toFixed，也会使后续`duration + .01`发生字符串拼接，影响截取边界判断。

修复：读取后将时长转换为有限正数，优先使用getVideoInfo，字段无效时使用chooseMedia返回的时长；两者均无效则给出明确的时长读取失败提示，不覆盖当前素材。只在元数据通过校验后更新this.info和预览path，清除旧错误状态。视频信息中的“本地处理”改为“本机编辑”，避免与导出画面联网检测混淆。

回归：新增真实页面choose流程测试，复现字符串时长导致选图失败，并覆盖无效字段回退、无有效时长不进入编辑。修复前两项失败，修复后完整69项测试通过。原抽帧毫秒单位、像素数据复制与不支持格式拦截测试保持通过。

实际界面：通过官方自动化SDK打开视频页面，用系统文件选择框选取work/miniprogram-v2/test-video.mp4。页面path成功设置，显示“视频2.0秒”，start=0、end=2、status=“已选视频，调整片段后生成GIF”。截图work/modal-fix/video-selected.png。未用模拟响应代替该实际选择。

# 手机 AI 创作界面优化

- 沿用现有奶油白 / 黄绿色，取消首屏密集的账户与价格说明。
- 四个玩法以 2×2 大按钮显示，选中状态明确；选中后只展示所需表单。
- 照片和视频选择改成明确的整块选择按钮，保留格式、大小与时长要求。
- 各玩法提供可点击例子，切换时保留各自未提交的描述草稿。
- 生成按钮就近显示服务端报价；参考视频时长未确定时不猜价格。
- 价格、隐私、任务规则放在可展开的说明区；生成前的扣点确认及余额不足引导保留。
- 初始不展示大块空结果；任务开始后展示作品区，图片和视频成功后定位至结果。
- 模型、账户、后端、价格、付款和小程序包未修改。

## 验证

- 现有 221 项测试通过，TypeScript 与生产构建通过。
- 实际浏览器检查 390×844 与 320×760；按钮、输入区和上传选择均未横向溢出。
- 实际点击生图例子、改图例子与玩法切换，确认描述草稿分别保留。
- 机械检查只提示原有动态媒体节点的空 src：它们初始 hidden，选图或生成后赋值，不会渲染为破图。
- 本轮没有新付费模型调用、充值或余额修改；不把界面检查称为新增真实生成验收。

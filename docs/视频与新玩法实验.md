# 视频与新玩法实验

用户已授权在分支上继续尝试，保留 main 和公开测试版。实验入口 video.html，照片入口维持现有链路。

## 首个交付：视频转 GIF

选本地视频 → 选择最长 6 秒片段 → 选预设 → 编辑文字与位置、速度、比例 → 预览 → 下载 GIF。

预设是可修改的起点：原片加字、反复横跳（来回循环）、倒带一下（倒放）。支持原比例或方形居中裁切，240/320 像素长边，10 帧/秒，0.5–2 倍速。首版一层文字，可拖动，也提供位置滑杆。浏览器能解码的视频可用，失败时提示换 MP4；GIF 无音轨。文件上限 100 MB；通过帧数上限控制内存。编码用 Worker，提供取消。仅浏览器处理，无上传接口。

| 玩法 | 动作设计 | 聊天用途 | 与捏脸的区别 |

## 实施与验收

1. 矩形 GIF 编码与时间采样测试先失败，再实现；保留照片方形接口。
2. 单独视频页面及本地加载、片段、预览渲染、Worker 导出。
3. 浏览器生成真实 WebM 测试素材，验证上传、编辑、三预设导出、取消、异常、移动端。
4. 用独立 GIF 解码器核对长宽、循环、不同帧、时长；构建包含两个入口。
5. 推送实验分支，不合并、不部署 main。客户端发送仍需真机实测。

## 本次验证结果（2026-10-09）

- 18 项单元测试、生产构建通过。
- 视频浏览器验证：真实 WebM 上传、三个预设、文字拖动、片段范围、竖屏／方形导出、取消、损坏视频反馈、390px 布局通过；请求限定本地来源。
- 生产构建额外验证：真实 H.264 MP4 上传、2 倍速导出通过。
- Pillow 独立解码：135×240 竖屏与 240×240 方形，循环、不同帧、1秒／1.8秒／0.5秒时长符合设定。
- 原照片浏览器回归：六个效果导出、人脸定位、模型失败手动回退、键盘与移动布局通过。
- 尚未真机验证此视频入口；实验版未合并、未发布。

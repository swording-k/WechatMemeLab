# 怪相馆微信小程序内测

在仓库根目录运行 `npm ci`、`npm run build:miniprogram`，在微信开发者工具导入本目录。AppID 为用户提供的个人小程序 `wxe487c77e0ea5329a`。照片/视频编辑在设备本地执行；所选素材与导出帧的检测副本会发送至微信内容安全接口。AI动作另使用腾讯云与阿里云，客户端不包含 API 密钥。

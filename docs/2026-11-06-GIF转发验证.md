# GIF 转发入口

照片与视频工作台生成 GIF 后，在“保存到相册”旁提供“转发给朋友”。两端复用 `miniprogram/lib/share-gif.js`。

- 优先调用微信 `wx.showShareImageMenu`，传入已生成 GIF 的本地路径，显式关闭小程序入口。不先保存相册、不重新编码、不创建公开素材链接。
- 图片分享接口不可用或非取消错误时，提示可改发 GIF 文件。只有点击“发文件”才调用 `wx.shareFileMessage`，文件名保留 `.gif`。
- 取消不触发兜底发送；无生成结果、生成中或重复点击不分享。原导出安全检测保持不变。
- 图片分享菜单回调不代表对方已收到，界面不显示“发送成功”。GIF 的聊天展示、播放与收藏须真机验收。

## 接口依据

微信官方类型仓库 https://github.com/wechat-miniprogram/api-typings 的 `types/wx/lib.wx.api.d.ts`：图片菜单接受本地图片路径，文件接口明确用于转发文件。未找到能保证各客户端 GIF 聊天展示的官方依据。

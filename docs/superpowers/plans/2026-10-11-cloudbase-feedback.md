# CloudBase 反馈后端与站内截图反馈

## 最新决定

用户随后明确授权临时共用 FitGenius 免费环境，保持函数、集合、存储与同步凭据独立，等自有服务器准备后迁出。不购买 CloudBase 套餐。

1. 实现反馈校验、图片类型/总量限制、原子限流、幂等提交、持久化队列、公开附件代理、公开状态查询及持有独立随机同步凭据的 CI 接口。
2. 站内支持三张截图的选择、预览和移除；图片仅在用户提交反馈时上传。正常的照片编辑素材仍本地处理。大静态截图在客户端缩小；GIF 保留动画。
3. GitHub Actions 使用 GITHUB_TOKEN 定时同步队列为 Issue，图片用固定云端代理地址引用。通过反馈 ID 标记检查重复，创建后回写链接。云端不保存 GitHub 个人令牌。同步凭据仅存 GitHub Secret 和云函数环境变量。
4. 新增后端单元和集成测试、模拟浏览器反馈测试；部署隔离资源，真实提交一条虚构测试反馈及截图，核验云端存储、附件内容、CI 创建的 Issue 和回写状态，然后关闭测试 Issue。
5. 发布前端，验证线上提交入口，记录生产状态。CI 同步是定时任务，不承诺立即建 Issue；成功提示仅表示后端确认持久化，失败保留输入。

# 怪相馆微信小程序体验版

在仓库根目录运行 `npm ci`、`npm run build:miniprogram`，在微信开发者工具导入本目录。AppID 为用户提供的个人小程序 `wxe487c77e0ea5329a`。不使用云服务，不包含 API 密钥，不依赖网页域名。

已适配：15 个原有预设（含自由捏图）、照片拖动/双指缩放取景、文字位置与大小、动作幅度和速度、撤销重做、240px/24 帧 GIF 编码、本地预览与相册保存入口。

真实设备验收前为开发版本：iPhone 和 Android 的相册 GIF 保留动画、聊天发送须分别实测；编译成功不等于相册和聊天验证通过。网页的视频编辑、人脸检测、复杂贴图直接编辑和截图反馈未迁移。

修改共享效果后须重新运行构建。`core/engine.js` 为生成文件，但随源码提交以便开发者工具直接导入。所有照片与生成 GIF 均只在本机处理。

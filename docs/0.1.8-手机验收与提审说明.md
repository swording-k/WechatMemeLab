## 手机验收

微信扫码进入开发版，点击「视频转 GIF」。使用之前出现问题的同一段视频，按下面的顺序操作：

1. 选择视频，确认能看到原片；在「截取片段」调整起止位置，点击「播放选中片段」，确认只循环所选片段。
2. 切换「画面取景」，点「正方形取景」。应直接出现视频和选框，不应一直转圈。移动选框、拖动四角后，点「使用这个区域」。
3. 再点「框选视频画面」，调整成不同的矩形并确认，检查可以正常返回编辑页。也试一次「取消」，确认不会卡住。
4. 在「字幕动作」修改文字，点击「预览成品」。检查文字、取景、片段及动作是否正确；读取期间可以取消。如果视频不兼容，应显示具体错误并恢复操作，不能一直等待。
5. 点击「生成 GIF 表情」，完成内容检测后保存到相册。从微信聊天的相册入口选择动图发送，确认实际会动，画面、文字与所选片段一致。
6. 返回首页选照片，制作并保存一张 GIF，确认照片主链路仍可用。

若有失败，记录所处步骤、页面底部的完整提示及视频格式即可。不要在取景正常但生成失败时将两者当作同一故障。

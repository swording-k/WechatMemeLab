# 怪相馆首版开发与验收

更新：2026-10-09。用户授权持续打磨产品想法、功能和审美，做成可分享访问的产品。

## 产品想法

熟人的脸比陌生模板更有聊天里的笑点。首版围绕“一张照片受到一个离谱小动作”，用捏、拉、揉及局部膨胀/扭曲表达亲近、欠揍、无语和憋笑。几秒预览，直接得到可保存的动图；不用写提示词。

核心审美是写真手部与真实照片的拼贴反差、可感知的接触、受压和恢复。照片铺满画面只是构图；不能把换背景当作质量改进。用户已否定圆形头像加卡通手，以及白底上移动照片的九个实验，这些均撤下。

## 六种首发玩法

| 玩法 | 视觉动作 | 适合的回复 |
| --- | --- | --- |
| 就捏一下 | 两侧手先靠近，脸横向挤窄，停顿后松开恢复 | 不许躲、让我捏捏 |
| 脸借我拉一下 | 抓住两侧，脸横向拉宽，放手恢复 | 欠揍、脸借我拉一下 |
| 揉到走形 | 双手上下错位揉动，脸局部非线性扭动 | 过来让我揉揉 |
| 憋成大头 | 五官局部膨胀，停住再恢复 | 憋不住了 |
| 脸都气歪了 | 局部扭转往复，保持照片外缘稳定 | 我没事啊 |
| 憋成一团 | 五官纵向挤成一团，短停顿后释放 | 不许笑 |

每个效果保留熟人的辨识度，也能去掉文案使用。不做助威、祝好运等用户已排除的主题。

## 用户流程与功能

上传照片 → 本地定位与取景 → 选择动作 → 可选改短句/力度 → 实时预览 → 下载 GIF → 分享文件或玩法链接。

- PNG/JPG/WebP ≤10 MB；大图本地缩小，超过 4000 万像素拒绝。
- 方图、9:16 和横图使用统一取景坐标；合照可选某张脸。定位失效时保留手动控制，不承诺任意照片都能识别。
- 高级设置折叠：速度、作用范围、左右/上下、照片位置、缩放、透明照片合成背景。
- 240px 推荐聊天尺寸；另有 320/480px。后台生成、显示进度、再次下载。
- 手机优先展示上传，模板横向浏览，再预览下载；键盘可控制参数，尊重减少动态偏好。
- 玩法链接只包含玩法、短句、力度和速度。接收者上传自己的照片；不分享私人照片。
- 文件分享只在浏览器确认支持时出现，不能用时保留下载。

## 首版边界与下一步

本轮交付可分享访问的完整制作工具。照片本地处理，无账号、支付、社区、照片云存储、AI 重建表情、抠图或微信/抖音收藏同步。

后续通过真实用户对动图的反馈判断哪些动作值得继续打磨，观察制作成功率、再次使用和朋友跟做，而不能仅凭模板数量预测流行。继续保留用户审美验收与客户端实测为独立证据。

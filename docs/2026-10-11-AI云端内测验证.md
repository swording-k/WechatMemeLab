# AI 云端内测验证（2026-10-11）

## 交付与分支

新功能在 `codex/minimax-ai-creation`，没有合入 main 或部署正式 AI 前端。本地入口 `http://127.0.0.1:5173/ai.html`。照片/文字生成、完全自定义动作、三条可修改玩法、画风/夸张程度/文案，以及生成视频一键进入原视频工作台已实现。

## 腾讯云

独立函数 `meme-ai-api` 已部署到用户授权的 FitGenius 免费环境，Nodejs20.19、512 MB、60 秒。独立集合 `meme_ai_jobs` / `meme_ai_budget` / `meme_ai_media` 与存储前缀 `meme-ai/`。API 密钥仅在云函数环境变量及忽略的本地配置；公网任务接口要求独立内测口令。本地 Vite 代理在服务端附加口令，前端产物密钥扫描通过。

- 真实 HTTP 配置接口返回 200 / ready；未鉴权任务返回 401；预算为零的创建返回 400，未创建收费任务。
- 临时云端探针使用模拟生成供应商、独立测试集合。首次并发创建同一 ID 仅调用一次模拟供应商，任务转 success，下一任务被预算阻止。再次调用恢复既有任务，不再提交。
- 实测发现并修复 `_id` 不能参与 set，以及事务读取必须使用 doc 的适配问题；已增加回归测试。
- 1,622,993 字节的合成 MP4 保存到腾讯云后，经短期存储地址两段读取，重组与原文件字节完全一致。此视频不是 AI 样片。已适配实际存储域名 tcb.qcloud.la。
- 正式内测账本仍为 budget=0 / spent=0。临时测试函数与数据在验证后清理，原 FitGenius 函数不修改。

## 本地验证

单元测试、TypeScript 与构建通过。浏览器模拟验证完全自定义、照片确认、断线后查询同一任务、生成结果取回、320/390px、IndexedDB 带入视频工作台及实际 GIF 编码。原视频的三条预设、竖屏/方形导出、取消/错误和移动布局回归通过；站内反馈浏览器回归通过。

## 重部署与迁移

先运行 `node scripts/prepare-ai-cloud.mjs`，安装函数依赖；使用 `cloudbaserc.ai.example.json` 准备忽略的私有配置，填写已确认预算和私有凭据。部署函数及 /meme-ai-api 路由；实际区域网关地址才是接口地址，CLI 打印的旧 service.tcloudbase.com 地址不作为依据。不要在聊天、日志、Git 或前端写入 API 密钥或内测口令。

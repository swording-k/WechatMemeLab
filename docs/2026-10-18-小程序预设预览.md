# 小程序0.1.2预设预览验证

## 改动

15个预设加入112×112循环GIF，三列卡片展示，含标题、标签和选中状态。提示“先看示例动作，点选后用你的照片制作”。自由捏图使用一个拉拽示例，不会自动覆盖用户自己的自定义动作。

示例复用现有授权示例照片、手部素材和共享drawFrame/encodeGif，不调用AI、不上传用户照片。无需在手机并行计算15份像素变形。image启用lazy-load，面板卸载时移除图片节点。资产合计1035388 bytes，15份均通过帧数>1、无限循环检查。

复用调研：网页已有静态缩略图和完整效果引擎；离线生成采用MIT许可@napi-rs/canvas 1.0.11，只临时安装，不引入小程序运行依赖。生成脚本scripts/build-preset-previews.cjs。

## 实测

- 官方自动化接口读取15个预设卡片、15张图片。
- 实际点击效果页签与第三个卡片，selected变为dog。
- 暂停主画布后，间隔600ms截取相同卡片区域，像素差异证实示例GIF在模拟器播放。
- 人工查看实际模拟器截图和15种效果合成图，卡片显示正常。
- npm test：56/56；网页构建、小程序共享引擎构建通过。
- 官方CLI上传0.1.2成功，1296730 bytes（约1.2MB）。未提交审核或正式发布。

证据保存在忽略目录work/preset-previews：effects.png、selected.png、contact.png、motion-a.png、motion-b.png、upload.json、preview.png。

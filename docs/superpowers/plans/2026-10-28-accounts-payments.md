# 统一账户与真实充值实施计划

目标：落地已授权的统一账户方案；支付未开通或未真实验收时维持免费，不宣称已上线收费。

- [ ] 服务端账户：微信身份固定账户、持久钱包0初始化、服务端鉴权及会话注销。
- [ ] 网页一次性登录码：浏览器秘密绑定、5分钟过期、小程序显式确认、事务兑换、限频及账户隔离测试。
- [ ] 原生账户页：自动恢复微信身份、账户号、免费状态、网页登录确认、订单与真实充值入口（未配置隐藏）。
- [ ] 网页账户页与创作适配：网页登录后使用同一微信身份，保留独立游客试用任务，不自动合并旧作品。
- [ ] 真实虚拟支付适配：参考腾讯官方签名实现，商品价格由服务端目录决定；查单确认到账，事务幂等入账；不相信客户端支付成功。
- [ ] 支付开关保持关闭直到账号后台配置、真实支付/重复通知/失败场景通过。
- [ ] 针对性失败测试先行；完整测试、两端构建、云部署及原生/浏览器实际交互验证。
- [ ] 提供验收包和真实状态，用户验收前不正式提审发布。

实现继续使用 codex/ai-motion-studio 工作树，不修改主checkout。账户使用独立 meme_accounts/meme_login_challenges/meme_account_sessions，订单钱包使用 meme_orders/meme_wallets/meme_wallet_events。复用现 CloudBase SDK、Node crypto、微信登录；不引入另一套认证供应商。

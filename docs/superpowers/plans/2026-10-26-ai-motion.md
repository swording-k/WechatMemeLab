# AI Motion Implementation Plan

**Goal:** 在独立网页内测接通两类动作任务，复用剪辑/GIF导出。
**Architecture:** Vite页面 + loopback Node HTTP + 阿里云异步适配 + 本地原子账本。
**Tech Stack:** TypeScript/Canvas/现有gifenc worker，Node22 fetch/FormData，ffprobe。

- [x] 合同测试：两种API请求/不同结果字段、OSS上传、错误、预算并发与持久化；运行 `node --test tests/motion.test.mjs` 先失败后实现。
- [x] provider.mjs：官方HTTP/OSS临时上传/受限结果下载；media.mjs：本地ffprobe核实素材。
- [x] jobs.mjs：http.mjs：先落账、幂等ID、失败不重提、查询恢复、loopback来源校验和结果下载。
- [x] 页面：保留已有样式、新增独立入口，两模式、示例动作填充、文件预览、真实状态、恢复、GIF与剪辑导入；复用历史AI分支gif/handoff并核实。
- [x] 密钥本地模板和无推理探针；不得打印Key。未提供Key时明确阻塞真实效果验收。
- [x] 适量测试、构建、真实浏览器及GIF解码；保存验证边界和运行地址。

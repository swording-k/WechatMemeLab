# 原生视频剪辑与成品预览

沿用用户已确认的手机固定画布编辑方式，补齐当前用户要求的片段选择、画面选区和可见预览；保持个人免费小程序，不增加云视频编辑或依赖。

- [x] 先用回归测试验证片段限制、自由矩形框的边界、同一渲染函数的裁剪/字幕坐标。
- [x] 新增原生视频渲染/剪辑纯函数，复用网页timeline和既有sampleVideo；旋转后取景，预览/导出同源。
- [x] 固定画布；片段/画面/文字三面板；起止滑动、当前时刻、播放选段；原片与成品切换。
- [x] 在当前时刻视频帧上绘制任意比例矩形，移动和拖四角调整；支持全画面/正方形快捷取景。
- [x] 预览在本机抽帧播放，支持字幕、倒放、往返；不触发内容检测，不创建可分享文件。导出才逐帧检测并编码GIF。
- [x] 缓存仅输出尺寸预览帧，任务期间禁用相互冲突的操作，隐藏/卸载时取消与释放。
- [x] 跑相关测试和完整测试、共享引擎构建、官方编译/界面检查，上传新版并提供二维码给用户真机验收。

不把开发者工具布局或模拟帧测试称为真实手机视频解码通过。开发者工具不支持VideoDecoder；手机验收由用户手动完成。

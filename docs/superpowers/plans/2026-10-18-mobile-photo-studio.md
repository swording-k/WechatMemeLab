# 手机照片编辑操作整理

**Goal:** 在手机竖屏同一工作区里完成选图、框选、选效果、改字与 GIF 导出，不来回滚动查找画布。

**Architecture:** 延用现有 Canvas、照片取景与图层手势；手机端把同一套真实控件放入画布下方的四个工具面板，桌面恢复原布局。照片位置输入保留内部数据接口，不再作为用户操作滑块。框选支持拖选、移动选区、四角缩放；照片支持双指缩放和拖动。新增独立 responsive studio 模块，不改 AI/费用逻辑。

**Tech Stack:** TypeScript、CSS Grid、Pointer Events、现有 Canvas/GIF Worker；不新增依赖。

采用理由：项目已有照片映射、框选、图层双指手势和导出能力，复用现有模块比引入完整裁剪组件更能保留变形位置、猫狗贴图和已有导出契约。

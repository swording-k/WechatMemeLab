# AI 动作表情创作

## 已确认方向

用户选择直接用 AI 生成指定动作的短视频，再转 GIF；不采用“生成静态图片后套现有变形”的方案。用户已选择 MiniMax，并提供 API 凭据用于本地服务端接入；文生使用 Hailuo 2.3，图生使用 Hailuo 2.3 Fast。目标是在传播前做出有具体笑点、可以反复用于聊天的作品。

## 产品入口与流程

在“照片整活／视频表情”旁增加“AI 创作”。第一屏可选择“用照片生成”或“从文字生成”，两种模式共用动作描述及玩法卡。

1. 用照片生成：选择一张照片，先在本地预览并确认主体，再选择玩法或自由描述；从文字生成：描述角色及其动作，不强制上传照片。
2. 玩法卡填入可编辑的动作描述和建议回复文案。用户可以改变对象、动作、夸张程度与画风，文案在成品编辑时叠加，不要求模型把中文文字画进视频。
3. 点击“生成动作”。显示真实的等待／生成／完成／失败状态，不伪造生成百分比。生成按钮不能重复提交同一个请求。
4. 成功后直接预览真实视频，提供“做成 GIF”“重新生成”和视频下载。重新生成是新的付费请求，需要明确区别于不花 AI 额度的编辑操作。
5. “做成 GIF”把视频带入现有视频工作台；选择最长 6 秒片段、取景、短句和循环方式，使用现有本地取帧与 Worker 编码下载 GIF，不要求用户下载后重新上传。

## 第一批玩法

只先打磨以下三条，不靠扩充数量证明好玩。每条都支持用照片中的人做主角，也支持文字创建原创角色。

### 我只是路过

- 动作：从画面边缘小心探头，偷偷看一眼；与镜头对视后僵住半拍，迅速缩回去。开头与结尾都保持人物藏在画外，便于循环。
- 聊天情境：想联系但嘴硬，偷看朋友在不在。
- 建议文案：“我只是路过”“你继续，我不打扰”。
- 可调：从左／右探头，害羞／欠揍的表情，缩回速度。
- 验收：小尺寸能看出“偷看→被发现→缩回”，人物仍可识别，不能只有相机平移。

### 嘴硬到下一秒

- 动作：人物故作镇定，努力忍住情绪；下一秒突然委屈大哭，随后擦掉眼泪迅速装回镇定。用短暂停顿制造反差。
- 聊天情境：被朋友调侃、破防却不肯承认。
- 建议文案：“我没急”“真的一点都不在意”。
- 可调：委屈／憋笑／惊慌，反差程度，恢复镇定的速度。
- 验收：不加文字也能看懂前后情绪反差；表情切换有动作过程，不是两张脸的硬切换。

### 收到你消息的我

- 动作：人物起初无精打采，看到消息后瞬间兴奋，长出狗耳朵，向镜头扑过来；撞到画面后停顿，再退回初始位置。
- 聊天情境：朋友终于回复、亲密关系中的热情回应。
- 建议文案：“你终于回我了”“我就蹭一下”。
- 可调：克制／疯狂的兴奋程度，扑过来的距离，人物／卡通画风。
- 验收：视觉重心是“看到消息后的反应”，变身不能把身份完全换成无关角色；扑近动作和碰到画面的停顿必须连贯。

## 服务接入

现有站点是 GitHub Pages 静态站。AI 的付费密钥必须留在服务端，不能放在 Vite 环境变量或公开仓库。若用户现有服务已提供可公开调用的任务代理，则复用该代理；否则增加独立服务端接口，前端 Pages 可保持原部署方式。

前端到本产品服务端的契约：

- 创建任务：输入模式、描述、玩法 ID 和可选照片；返回任务 ID 与排队／处理中状态。
- 查询任务：返回真实状态、可读错误和成功后的受控视频资源；前端采用有间隔的查询，避免等待时重复创建任务。
- 读取结果：使浏览器能够读取视频字节，确保 Canvas 取帧不因跨域失败；不接受用户任意填写的远程视频 URL 作为代理目标。
- 服务端负责真实服务适配、密钥、用量限制和错误转换。时长、图生视频／文生视频支持及预算提示以用户提供模型的真实能力为准。

模型生成属于异步任务。离开页面不谎称已取消计费；仅在供应商支持取消且确认成功时显示“任务已取消”。任务提交失败不得自动重复创建收费任务。暂停等待与重新生成分别处理。

## 照片与配置

普通照片整活和本地视频转 GIF 的本地处理方式保持。AI 创作页面必须明确显示照片会发送给实际选中的生成服务，生成按钮前能看到缩略图及接收方；不能继续对 AI 页面宣称“照片只在设备上处理”。

配置只读取用户指定的本地文件或环境变量，不把密钥发到聊天、日志、玩法链接或 Git。日志只记录任务状态和必要错误，避免记录照片内容。公开入口需在服务端设置单人并发及总额度限制，具体额度在服务费用确认后设置。

## 验证与发布判据

- 使用实际服务完成一次文生视频、一次图生视频，生成视频必须可观看，不把示例素材冒充 AI 成功结果。
- 每条玩法至少观看一份无字和一份有字的 GIF；先用虚构示例人物验证，再由用户决定是否提供自己的照片。
- 从 AI 完成页一键进入视频编辑，不重复上传，GIF 可解码、播放和下载，手机能完成整个流程。
- 验证超时、服务拒绝、余额不足、重复点击、离开后返回和无法解码的视频；失败保留输入，不能吞掉照片或描述。
- 玩法链接分享动作描述及设置，不包含上传照片、密钥或私人结果地址。
- 技术通过与趣味性验收分别记录。先让用户选出真正愿意发给朋友的成品，再安排对外传播。

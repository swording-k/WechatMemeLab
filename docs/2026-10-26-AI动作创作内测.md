# AI 动作创作内测

## 已交付

独立分支 codex/ai-motion-studio，工作区 /Users/baojian/.codex/worktrees/ai-motion-studio/WechatMemeLab。未合入主分支、未部署、未改已审核小程序。

motion.html 有照片写动作、照片学参考动作两入口，照片/视频本地预览、字幕、任务恢复、生成视频下载、本地240px GIF及导入原有视频编辑器。参考视频限制2～6秒/20MB，服务端用ffprobe核实时长和尺寸。

服务端调用 wan2.6-i2v-flash（720P/2秒/audio=false）或 wan2.2-animate-move（wan-std）。动作迁移先通过官方私有OSS临时上传再提交；临时存储是内测方案，不用于生产高并发。Node原生fetch/FormData，不新增运行依赖。历史AI分支只提取本地GIF及IndexedDB交接模块，未引入旧MiniMax生成或密钥。

任务创建前原子落账，单并发、幂等ID及素材指纹，默认最多2次、预留预算3元。供应商明确拒绝不预留费用，网络提交不确定保留额度且不自动重提。估算按北京官网价：图生2秒0.30元，动作迁移0.40元/秒按整秒保守预留；不是实际账单，不能证明账号免费额度。

## 本地启动与密钥

- 主目录 /Users/baojian/Desktop/WechatMemeLab/.env.motion.local 已创建空模板，权限600，被Git忽略；隔离工作区通过本地软链接读取。
- 在 DASHSCOPE_API_KEY= 后填写阿里云百炼通用Key（不是阿里云AccessKey或Coding Plan专用Key）。默认北京API域名；其他地域需匹配地域与账号。
- 在隔离工作区运行 `npm run check:motion` 仅查询模型列表，不创建推理任务。查询成功也不等于具体模型权限、免费额度或效果通过。
- `npm run dev:motion` 后端127.0.0.1:8790；`npm run dev -- --port 5180 --strictPort` 网页 http://127.0.0.1:5180/motion.html 。填写Key后重启后端。
- 不将Key放进VITE变量或前端输入框，不在日志输出。
- 本机需ffprobe（当前已有）。生产发布前另做账号授权/用户额度与存储方案；当前仅本机内测，不能直接公开代理付费调用。

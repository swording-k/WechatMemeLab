# MiniMax 动作表情接入计划

目标：按已确认的直接生成视频路线接入 MiniMax，并带入现有视频工作台制作 GIF。使用原生 Node HTTP 服务端、TypeScript 前端、现有视频 Canvas 和 Worker 编码。

- [x] 核对官方文生视频、图生视频、异步查询、视频下载及计费文档；文生使用 Hailuo 2.3，图生使用 2.3 Fast，固定 768P／6 秒。
- [x] 先运行失败的请求和状态转换测试；实现独立 MiniMax 适配器，测试密钥不出现在错误响应。
- [x] 服务端创建／查询／取回视频，持久化任务和预算，创建任务幂等，未知提交结果不自动重试。
- [x] 加入 AI 创作页、三条玩法、照片预处理、任务恢复和真实视频预览；生成结果通过 IndexedDB 带入视频工作台。
- [ ] 验证文生／图生到 GIF 的完整流程和错误恢复；免费自动测试与收费真实样片分别记录。
- [ ] 用户确定测试预算后验证真实服务；公网部署需要可保管密钥的服务端，不将付费密钥部署到 GitHub Pages。

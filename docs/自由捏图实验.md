# 自由捏图实验

用户已授权在实验分支添加自由捏图。入口放在所有预设最前面。

上传图片 → 选择自由捏图 → 拉拽局部／点击鼓起／点击缩小 → 多次叠加 → 撤销或清空 → 查看原图到变形再恢复的循环 → 加字、调力度和速度 → 导出 GIF。

编辑时显示变形峰值并定格，让用户看清当前形状；播放时隐藏操作辅助线。最多 12 次操作，每步独立记录位置、范围和方向。坐标归一化以保证预览和导出一致。换照片清空操作；切换预设保留自定义草稿。鼠标和触屏均使用 Pointer Events，手机只在编辑画布上阻止滚动。为键盘提供局部方向按钮。草稿不保存到服务器，不加入分享链接；自定义模式分享作品 GIF。

这是局部变形编辑器，首版不包括自由绘画、贴纸图层或逐帧时间轴。若需要这些能力，可作为后续独立扩展。

验证：逆映射边界、零强度与方向、叠加顺序；浏览器真实拖动、点击笔刷、撤销清空、切换保留、换图重置、GIF 动画导出；手机布局和触屏。

新的聊天玩法先按触发场景筛选，而非不断增加捏脸变体：催回复→被消息震飞；嘴硬→脸先破防；贴贴→挤进屏幕；困到不行→灵魂出窍。以上仅为方向，尚未制作。

## 本轮验收

20 项单元测试与构建通过。浏览器验证鼠标拖动、两种点击笔刷、撤销清空、键盘方向按钮、编辑定格与播放、导出后再次编辑、草稿切换保留和换图重置。使用 Chrome 真实触摸事件验证手机拖动，390px 布局无横向溢出。Pillow 独立解码确认 240×240、1.6 秒、多帧变化及无限循环；导出不含编辑辅助圈。原六个效果与四个新增效果的浏览器回归通过。真机触感和趣味仍待用户验收。
